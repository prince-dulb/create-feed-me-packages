# 依赖与安装边界

| 项目 | 声明／实际验证 |
| --- | --- |
| Minecraft | 1.21.1，必需 |
| NeoForge | 声明21.1.219起；实际验证21.1.219及21.1.249 |
| Create | 必需；声明6.0.10起、低于6.1.0；实际6.0.10-280 |
| Curios | 必需；声明9.5.1起、低于10.0.0；实际9.5.1+1.21.1 |
| JEI | 非依赖；NF249下实际验证19.51.0.417及418 |
| Package Couriers（纸飞机） | 非依赖；实际验证2.3.0 |
| Create: Mobile Packages（运输蜂） | 非依赖；实际验证1.21.1-0.7.7 |

模组元数据只声明Minecraft、NeoForge、Create、Curios。JEI和两种运输均没有required或optional依赖条目；不安装它们可以加载核心，但实际远程配送仍需要你建设运输设施。Create自身需要的运行库按Create的安装要求处理，不由FMP重打包。

退出游戏后，在独立测试实例中使用本JAR。旧FMP文件由你移出实例的mods目录，避免同时加载；本交付不会替你删除文件。客户端与服务端应使用同一test.14；取料显示协议已更新，不支持与test.13混连。

本次未改持久化schema，但没有承诺旧测试世界兼容或执行任何迁移。先备份世界，不要在唯一的正式存档上试包。未测试你的完整PCL整合包。

已知上游问题：纸飞机2.3.0有引用Factory Logistics的配方；与运输蜂共存时另有两条便携发报器配方引用不存在的上游物品。测试日志记录这些外部错误；未修改第三方JAR，FMP自己的20条配方正常载入。
