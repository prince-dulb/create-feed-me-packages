# 请优先复测这两条

在独立测试世界中安装本版，客户端与服务端保持一致。完整操作见[供应链坠使用说明](../../reference/v0.1.0/docs/PLAYER_GUIDE.md)。

## 1. 创造模式关闭背包不复制

不建设该物品的补货体系。准备1块木板，存入缓存，再取到光标并放进原版背包，关闭／重开；随后切生存、退出重进。正常结果始终合计1块，服务端数量不增加，也不产生额外掉落。

再分别用一整组和超过一组的缓存数量重复。若异常，反馈游戏模式、点击方式、关闭前光标是否拿着物品、各处实际数量及录屏。

## 2. 请求64个原木后只合成一次

清空普通背包中的原木，缓存最低设64，等待真实首包到齐。

1. 在JEI选木板配方并填充，但不拿产物：缓存仍为64，工厂不应为准备新发包。
2. 关闭界面，再重复选择和取消：库存、工厂总出货仍不变。
3. 再次准备并取一次产物：得到4块木板；缓存真实消耗1个，最多为这个缺口补发1个。
4. 关闭后等待补货：缓存回到64，不应因自动准备下一轮而额外发货。

也请用原版配方书、连续合成、背包接近满位，以及有桶余物的配方试一次。自动测试已覆盖这些事务边界，但不能替代你的完整整合包体验。

## 顺手检查

- 背包有材料时先消耗背包，不再显示优先级开关。
- 潜行右键网络设备绑定后，链坠出现光效；清绑后恢复。
- 创造标签页／JEI显示四种扩容链节1—4号，最后一号用于升到5级。
