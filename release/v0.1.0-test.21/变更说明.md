# Create: Feed Me Packages! 0.1.0-test.21 — 变更说明

## 相对于 test.20 的变更

### 修复滑条拖动范围与数字输入仍用旧逐物品组容量

- `commitNumber()` 和 `setDraft()` 中的 `snapshot.capacity() / stackSize`（逐物品组容量，如末影珍珠 128÷16=8 组）遗漏未改为 `snapshot.groupCapacity()`（统一组容量 2 组）。
- **影响**：末影珍珠滑条可拖到 128（而非 32）、牛奶桶可拖到 128（而非 2），松手后服务端拒绝回弹。小堆叠物品受影响最严重。
- **修复**：两处改为 `snapshot.groupCapacity()`，与渲染和滚轮逻辑一致。

### 验证结果

- JUnit：16/16 通过
- GameTest：84/84 通过
