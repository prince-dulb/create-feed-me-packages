# v0.1.0-test.17 依赖说明

本目录是本地测试交付，不是公开发布版。

## 加载器依赖

- Minecraft `1.21.1`
- NeoForge `21.1.219` 及以上（组合验证覆盖 21.1.249）
- Create `6.0.10`（低于 6.1.0）
- Curios `9.5.1`（低于 10.0.0）

生成后的 `neoforge.mods.toml` 只有上述四项 required 依赖，0 项 optional。JEI、纸飞机（Package Couriers）、运输蜂（Mobile Packages）均为运行时可选，缺失不阻止加载。

## 数据格式

- 玩家缓存 schema **3**：最低/最高阈值改按"组"计数（组 = 物品原生堆叠上限）。schema 1/2 测试世界载入被拒绝并整记录保留，请新开存档测试。
