# v0.1.0-test.7 依赖说明

本目录是本地测试交付，不是公开发布版。

## 加载器依赖

- Minecraft `1.21.1`
- NeoForge `21.1.219`
- Create `6.0.10`
- Curios API `9.5.1+1.21.1`

与 `test.6` 完全一致：生成后的 `neoforge.mods.toml` 只有上述四项 required 依赖，JEI、Create More: Package Couriers、Create: Mobile Packages 均未声明为 required 或 optional，缺失这些模组不阻止核心加载。

本构建是 `test.6` 人工测试反馈的修复版，玩法范围没有扩大：补货请求、本地收包、残包续收、切点守恒的边界与 `test.6` 相同，新增的是服务端快照推送、客户端无快照即时请求与四项转移守恒回归测试。
