# v0.1.0-test.10 变更说明

本构建实现[决策 0001：精确组件物品身份](../../docs/decisions/0001-精确组件物品身份.md)，把缓存、过滤、待收、收包、配方取料与弹药取用的身份口径全部换成"物品注册 ID＋完整持久化组件"，并按技术审查重写 T12 的扣减提交点。玩法入口与 `test.9` 一致。

## 缓存身份：精确变体（决策 0001）

- 新增不可变 `ItemVariantKey`（物品＋完整持久化组件，数量不计入身份），作为物流格过滤、库存、待收与包裹日志的唯一身份。
- **同种物品的不同组件状态不再混算**：改名石与普通石是两个变体；附魔书按其实际附魔独立成格；装有物品的潜影盒按其实际内容独立成格（内容物原样保留，不做破坏性去数据）。
- **取消"特殊物品默认化＋二次确认"流程**：手持含组件物品放入空格，一步建立精确变体过滤并存入实物；来源物品不变。
- 建立重复过滤、非空格改过滤、待收与过滤修订等既有防护在变体口径下保留；服务端补货/收包校验请求变体必须与来源格过滤变体一致。

## 存档迁移：schema 1 → schema 2

- 旧玩家数据载入时自动迁移：逐字段无损转换为精确变体身份；迁移后立即按 schema 2 保存，重复载入幂等。
- 迁移遇到无法解析的物品 ID（模组被移除等）时**整条记录封锁**（BLOCKED_CORRUPT），原始 NBT 完整保留，不静默清空任何字段；修复依赖后可恢复。
- 迁移夹具测试用手写 schema 1 NBT（独立于当前 codec）验证无损迁移与封锁路径，并用 GameTest 跨 JVM 回读验证真实存档路径。

## T12 重写：弓弩弹药的扣减提交点

按 [规格 06](../../docs/开发计划书/specs/06-弓弩弹药取用.md) 与技术审查结论修正：**查询零扣，真实消耗点单扣**。

- 查询（`LivingGetProjectileEvent`）只提供脱离副本，不再扣缓存；反复查询不改变数量与修订号。
- 真实扣减发生在原版共享的 `ProjectileWeaponItem.draw` 消耗点（单个 Mixin 观测）：弓在过拉力门槛后的实际放箭时扣 1；弩在装填完成写入 `CHARGED_PROJECTILES` 时扣 1；发射已装填的弩不再重复扣。
- 无限箭、创造模式、弓箭 Infinity 等原版不消耗的路径不扣缓存；取消蓄力（拉力不足）不扣缓存。
- 背包有箭仍优先背包；无吊坠、全部禁用或异网冲突时完全原版行为。
- 多重射击按原版口径：一次装填/一次放箭只扣 1。
