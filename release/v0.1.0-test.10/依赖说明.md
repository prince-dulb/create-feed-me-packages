# v0.1.0-test.10 依赖说明

本目录是本地测试交付，不是公开发布版。

## 加载器依赖

- Minecraft `1.21.1`
- NeoForge `21.1.219`
- Create `6.0.10`
- Curios API `9.5.1+1.21.1`

生成后的 `neoforge.mods.toml` 只有上述四项 required 依赖，0 项 optional（`ResourceContractTest` 固定）。JEI、纸飞机（Package Couriers）与运输蜂（Mobile Packages）均不写入依赖声明，缺失或版本变化不阻止加载。

## 可选集成（未安装不阻止加载）

- **JEI**（编译基线 `19.51.0.418`，1.21.1 NeoForge）：安装后自动启用配方书取料的 JEI 转移与物流格 ghost 拖入；ghost 拖入现按精确组件变体设置过滤。未安装时两者自动缺席，原版配方书取料不受影响。
- **运输模组**：无需专用适配。纸飞机与运输蜂按原版玩法使用；补货包裹送到背包后由本模组自动拆入缓存。

## 数据格式变化（相对 test.9）

- 玩家缓存持久化格式升级为 **schema 2**（[决策 0001](../../docs/decisions/0001-精确组件物品身份.md)）：缓存身份从"物品注册 ID"变为"物品注册 ID＋完整持久化组件"（`ItemVariantKey`）。
- 旧 schema 1 存档数据在载入时自动迁移：物资数量、格位设置、待收记录与包裹日志逐字段无损保留；遇到本模组不认识或无法解析的物品 ID 时，整条记录保持封锁原样保留（BLOCKED_CORRUPT），不静默清空。
- 手动重置在途、过滤、待收等行为在 schema 2 下语义不变，仅身份口径更精确。
