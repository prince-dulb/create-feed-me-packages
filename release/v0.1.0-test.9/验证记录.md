## 请人工复测（一锅验收）

**A. 配方书取料（生存模式，佩戴供应链坠，缓存有材料）**

1. 背包空、缓存有 4 个原木 → 配方书点"橡木木板"：网格出现 1 根原木、缓存剩 3、结果槽出现 4 块木板。
2. 背包 3 根 + 缓存若干，点配方 → 背包优先先扣背包；切"缓存优先"开关后再点 → 先扣缓存。
3. 材料不足时点配方：网格、背包、缓存全部不变，出现红色提示。
4. MAX 填充：缓存材料充足时格子一次堆到 64（不超堆叠上限）。
5. 工作台上：清格时背包满 → 整体拒绝不掉落。
6. 合成后关闭工作台：网格材料按原版退回背包（缓存不自动回收）。
7. 卸下坠子后点配方书：原版照常放置（只用背包材料），不借缓存。

**B. JEI（在实例中安装 JEI 19.51.x）**

8. JEI 拖物品到物流格 → 只设过滤，来源物品不变。
9. JEI 配方转移（+Shift 为 MAX）→ 材料进网格、缓存等量扣减。

**C. 弓弩**

10. 背包无箭、缓存有箭：拉弓 → 箭上弦、缓存减 1；连续射击逐支扣减。
11. 背包有箭 → 优先背包，缓存不动。无限附魔不消耗；多重射击在缓存仅 1 支时按 1 支消耗（原版一致）。
12. 卸下坠子 → 弓不可从缓存取箭，缓存数据保留。

**D. 原生运输联调（此前已列，未覆盖项）**

13. 安装 Package Couriers 2.3.0 + 定位发信器：把 `FMP@玩家名` 包裹装入纸飞机零件、投掷或弹射器发射 → 包裹进背包后自动拆入缓存。
14. 预拆模式（若模组内可触发）确认为不支持诊断。
15. Mobile Packages：网络成员收 `FMP@` 完整包 → 自动拆入缓存；非成员不收；背包满时包裹不消失、不误记缓存到货。
