# v0.1.0-test.9 依赖说明

本目录是本地测试交付，不是公开发布版。

## 加载器依赖

- Minecraft `1.21.1`
- NeoForge `21.1.219`
- Create `6.0.10`
- Curios API `9.5.1+1.21.1`

生成后的 `neoforge.mods.toml` 只有上述四项 required 依赖，0 项 optional（`ResourceContractTest` 固定）。

## 可选集成（本构建新增，未安装不阻止加载）

- **JEI**（编译基线 `19.51.0.418`，1.21.1 NeoForge）：安装后自动启用配方书取料的 JEI 转移与物流格 ghost 拖入；未安装时两者自动缺席，原版配方书取料不受影响。
- **运输模组**：无需专用适配。纸飞机（Create More: Package Couriers `2.3.0`）与运输蜂（Create: Mobile Packages）按原版玩法使用即可；补货包裹送到背包后由本模组自动拆入缓存。
