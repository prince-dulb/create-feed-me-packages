## 请人工复测

1. 生存和创造模式分别打开背包，确认左侧面板都出现，滑条只显示在所选格下方或空间不足时上方。
2. 用创造目录物品设置过滤，确认缓存数量仍为 0；背包中的真实物品可以存入缓存。
3. 物流格只剩不超过一组物品时取出，确认物品留在光标上，不会丢到地面。
4. 供应链坠分别潜行右击 Stock Link、Stock Ticker 或 Redstone Requester，确认均可绑定。
5. 绑定后装备坠子，给缓存格设置过滤，将左端最低值设为 32 并启用。普通背包里是否已有同物不应影响请求；缓存低于 32 时等待最多 1 秒，确认网络打包机生成地址为 `FMP@你的玩家名` 的包裹，且不会连续生成重复包。

本构建还不会在包裹抵达玩家背包后自动拆入缓存；该步骤属于 T06 后续实现。
