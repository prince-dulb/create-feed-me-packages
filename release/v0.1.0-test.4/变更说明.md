# v0.1.0-test.4 变更说明

本构建针对 `v0.1.0-test.3` 的实际游玩反馈修订：

- 供应链坠可潜行右击任意实际挂载 Create 物流网络行为的方块进行绑定，不再写死 Stock Link。
- 左侧物流面板同时支持生存与创造模式背包；创造目录物品只设置幽灵过滤，不生成库存。
- 面板和物流格改用 Create 的配色、边框与请求槽贴图；阈值设置改为当前格下方的紧凑双端滑条。
- 缓存点击会消费对应的鼠标释放事件，修复最后一组取到光标后被原版当作界面外点击丢出的竞态。
- 新增补货请求侧：有效佩戴时每 20 tick 检查缓存最低值，通过绑定网络中的真实 Create 打包机抽料并生成 `FMP@玩家名` 包裹。
- 新增待收防重。派发开始后若结果不确定，保留待收并等待玩家按格手动重置，不自动重复请求。

当前尚未实现专用地址包裹自动拆入缓存、待收结算与残包续收，因此这仍是阶段测试构建。
