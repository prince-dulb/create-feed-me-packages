本构建保留 `v0.1.0` T05 面板与光标同步修复，并新增以下依赖调整：

- 删除 JEI、Package Couriers、Create: Mobile Packages 的全部加载器依赖声明。

- 删除当前尚未使用的 JEI Maven 仓库、版本属性和 `compileOnly` API。

这是 `release/v0.1.0/` 之后的新测试构建；旧目录保留作为历史产物，测试时请只使用本目录中的 JAR。
