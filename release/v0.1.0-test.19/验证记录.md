## 修复要点

1. **容量模型回退**：`CacheLevel.capacity()` 保持物品口径（1 级 = 128），`groupCapacity = capacity / stackSize` 仅用于阈值校验与滑条范围
2. **MaterialHints 上限**：从 2048 提至 4096，容量回退后不再被超出
3. **Schema 4**：接受 schema 2 迁移（阈值 ÷ stackSize），拒绝 schema 3
4. **GameTest 换算**：全部阈值调用从物品数改为组数（128→2, 120→2, 100→2, 37→1, 32→2 等）
