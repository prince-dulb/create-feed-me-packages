# v0.1.0-test.3 依赖说明

本目录是 T05 本地测试交付，不是公开发布版。

## 加载器依赖

- Minecraft `1.21.1`
- NeoForge `21.1.219`
- Create `6.0.10`
- Curios API `9.5.1+1.21.1`

生成后的 `neoforge.mods.toml` 只有上述平台／模组依赖。JEI、Create More: Package Couriers、Create: Mobile Packages 均未声明为 required 或 optional，不会由本模组元数据限制其版本。

JEI 与两种运输附属仍是后续兼容目标；当前尚未实现 JEI ghost、配方转移或双运输闭环。移除依赖声明只解决加载器拒绝，不代表这些功能已兼容。
