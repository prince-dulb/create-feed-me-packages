# v0.1.0 T05 测试构建依赖

本目录是本地游戏内测试交付，不是公开发布版，也不表示 T05 或 `v0.1.0` 已完成。

## 必需环境

- Minecraft `1.21.1`
- NeoForge `21.1.219`
- Create `6.0.10`
- Curios API `9.5.1+1.21.1`

将 `create-feed-me-packages-0.1.0.jar` 放进同一实例的 `mods/` 目录。Create 自身要求的运行依赖仍须按 Create 的发布说明安装；本次开发运行实际加载了 Flywheel `1.0.6` 与 Ponder `1.0.82+mc1.21.1`。

## 当前不需要安装

JEI、Package Couriers 和 Create: Mobile Packages 在模组元数据中是可选依赖，但其 ghost 过滤、纸飞机与运输蜂兼容任务尚未完成。本测试构建只验收 T05 核心缓存面板和交互，不能据此判断这些兼容已经可用。
