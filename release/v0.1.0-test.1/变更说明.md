# v0.1.0 T05 测试构建变更

## 本次可测试内容

- 原版生存背包左侧物流缓存面板。
- 从玩家物品栏向缓存设置默认物品过滤并转入真实库存。
- 左键、右键、Shift 左键及双击归集的存取语义。
- 特殊组件物品的默认模板二次确认。
- 每格最低／最高端点、滚轮与数字精调、来源优先级、在途手动重置。
- Curios 供应链坠的佩戴、重装、禁用、清绑与多终端管理入口。
- 石头至坚固板五阶段升级件及当前简化配方。

## 本轮缺陷修复

- 修复空物流格仍保留阶段容量上限时被快照编码误判，进而在供应链坠重新装备、关闭并重开背包后断开连接的问题。
- 过期的周期性只读快照请求在 Curios／原版背包菜单切换后直接丢弃，不再误报写操作失败。
- 新增受菜单号、默认物品模板与原生堆叠上限约束的服务端光标快照。
- 双击归集等待第一次取出对应的缓存修订与光标同步后再提交，不并发发送两笔互相竞争的请求。
