# Create: Feed Me Packages! 0.1.0-test.24 — 依赖说明

## 模组依赖声明（`neoforge.mods.toml`）

只声明以下四项 required 依赖，未新增可选依赖：

| 依赖 | 版本 | 关系 |
| --- | --- | --- |
| Minecraft | 1.21.1 | required |
| NeoForge | 21.1.219 | required |
| Create | 6.0.10（Maven `6.0.10-280`） | required |
| Curios | `9.5.1+1.21.1` | required |

JEI、Create More: Package Couriers、Create: Mobile Packages 等**不写入依赖声明**；实现兼容时使用隔离模块与运行时存在性探测。

## 实际测试组合

- 核心（无 JEI/运输）GameTest：NeoForge 21.1.219，`-model8` 世界。
- 跨 JVM 回读：同上，读前一 JVM 写入的真实玩家文件、Curios 与 schema 7 缓存账本（含物主锁定、物主缓存等级、迟到包路由、撤销副本）。

## 数据格式

- `CacheLedger.SCHEMA = 7`（私人定坠物主锁定；去除授权 grants 字段）。
- 私人定坠新增 `OWNER`（UUID）与 `OWNER_NAME`（物主名）数据组件。
- 提供 schema 2/4/5/6→7 迁移（旧缓存与残包迁移；旧 schema 6 世界里的授权表视为废弃忽略）。
- 未发布内部测试世界、旧 `test.N` 数据不构成存档兼容合同；旧 `-model7` 等世界目录保留未删。

## 兼容边界

- 本构建未接入 JEI / 纸飞机 / 运输蜂的完整联调（沿用上一轮）。
- 缺失 Create / Curios 时加载器按 required 声明拒绝（已有探针，本轮未重跑）。
- 私人定坠钥匙：只有物主可访问/升级；非物主佩戴会退化为全新普通坠。
