# 依赖与实测组合

## 必需

| 项目 | 建议复现版本 |
| --- | --- |
| Java | 21 |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.249；无新 JEI 时核心另测过 21.1.219 |
| Create | 6.0.10，对应 Maven 6.0.10-280 |
| Curios | 9.5.1+1.21.1 |

元数据只声明 Minecraft／NeoForge／Create／Curios，没有 JEI、纸飞机、运输蜂或其他 required／optional 依赖。Create 自身的配套依赖遵循其官方安装方式。

声明范围为 Minecraft `[1.21.1]`、NeoForge `[21.1.219,)`、Create `[6.0.10,6.1.0)`、Curios `[9.5.1,10.0.0)`；版本范围可满足加载条件，不代表范围内每个版本都已测试。

## 可选

| 模组 | 本次实际测试版本 | 作用 |
| --- | --- | --- |
| JEI | 19.51.0.417、19.51.0.418 | 精确 ghost 拖入、配方填充、序列和锻造成品展示 |
| Create More: Package Couriers | NeoForge 2.3.0 | 纸飞机原生配送 |
| Create: Mobile Packages | 1.21.1-0.7.7 | 运输蜂原生配送 |

JEI418 本身需要更高的 NeoForge；本次在 21.1.249 验证，不在 21.1.219 绕过其要求。纸飞机单装、运输蜂单装、两者共存与全部不装均测过。

运输设施仍由玩家按原模组规则建设。纸飞机需要其原生有效玩家目标；运输蜂需要正确网络成员。FMP 不替它们定位、入网、增加范围或强制加载区块。

## 已知上游问题

纸飞机2.3.0的 jar_plane 配方引用另一个未安装模组的物品；与运输蜂共存时另有两条便携发报器配方引用未注册物品。组合日志会有三条上游配方错误，FMP自身20条配方正常载入。这不影响本次 FMP 补货与缓存用例，但不能因此称整个第三方组合无错误。

未测试的整合包和其他可选模组版本需要单独复核。本包未写入你的现有实例。
