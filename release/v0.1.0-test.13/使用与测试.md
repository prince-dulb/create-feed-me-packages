# 使用入口与游玩反馈

完整操作说明见 [供应链坠使用说明](../../reference/v0.1.0/docs/PLAYER_GUIDE.md)。这是新缓存模型，请在单独测试世界里试，不沿用唯一的游玩存档。

## 最短上手流程

1. 制造或从独立创造标签页拿普通供应链坠；手持潜行右键实际Create网络设备绑定。
2. 戴进Curios有效项链槽，打开背包。背包拖实物是存入；JEI拖入只设过滤。
3. 点格子角落小点，设置最低数量。准备网络现货、打包机和原生配送设施；缺口只看缓存数量。
4. 缓存格左键取一组、右键取一件，Shift取到背包；取空后Ctrl＋右键清过滤。取料优先级在底部“背／存”切换。
5. 升级先制造序列链节，再在锻造台放装配图、坠子和链节，取成品才提交。装配图复用；私人化与普通升级使用同一制造入口。

## 请重点体验

| 场景 | 希望得到的反馈 |
| --- | --- |
| 从1级逐步升到5级 | 哪一级材料获取或产线建设突然不合理？高阶投入是否来自新材料和工艺？已有自动化后哪些成本完全失去意义？ |
| 实际GUI缩放、生存／创造、JEI共存 | 箭头／小点是否可见好点；局部滑条是否好调；高等级滚动是否费劲；提示是否容易理解 |
| 普通缓存转交、任意等级私人化、继续升级 | 库存／过滤／阈值是否符合预期；全量拒绝和待签收提示是否说清原因 |
| 背包塞满收货、超量到货、取回残包手拆 | 是否仍能正常补货；可见残包是否碍事，还是应按此前想法改成不可见表现 |
| 原版／JEI合成、弓／弩、来源优先级 | 切换是否符合直觉；配方余物与满位提示是否清楚；背包无弹药后是否顺畅接用缓存 |
| 自己的纸飞机／蜂布局 | 实际长距离、离线重进、传送或工厂卸载后由原运输规则怎样处理；发生问题时保留日志与原包，不先反复重置请求 |

这些是实际整合包与体验复核，不表示对应自动测试尚未做。测试分层结果见 [验证记录](验证记录.md)。本版没有退货或TaCZ适配，不需要按这些功能测试。

反馈时附：FMP版本、NeoForge／相关模组版本、发生前做了什么、期望与实际结果、截图及该实例的latest.log。若涉及数量，记录缓存、背包、包裹和网络四处的变化；出现异常时先保留现场。
