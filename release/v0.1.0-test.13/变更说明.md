# 独立参考实现说明

本次 test.13 来自 `reference/v0.1.0/`，不复用根工程旧实现，不提供旧测试世界的数据迁移。

## 核心功能

- 两种缓存归属：普通坠子带走整份本件缓存，私人定坠访问当前佩戴者的个人缓存；死亡本身不删除缓存。
- 每次服务端操作重新核对 Curios 佩戴、启用状态、网络和活动缓存；多网／多缓存冲突可在管理入口恢复。
- 完整组件物品身份；实物、过滤和请求分离，缓存只统计自身库存。
- 真实 Create 请求和专用包封签，固定目标玩家、缓存、请求及过滤生命周期。实际库存达标即隐藏下箭头，手动重置只清请求记录。
- 满背包服务收件、部分拆包、单一真实残包和腾位续收；拒收保留原包。
- 生存／创造面板、双端局部滑条、滚动、精确 JEI ghost 和独立创造标签页。
- 共享取料事务覆盖原版 2×2／3×3、配方书、JEI和标准投射物链；支持背包优先／缓存优先、混合补足、余物和失败守恒。

各级自有序列均为一轮、80%成功，不按等级降低成功率或累加同工序循环。材料数量是明确的参考配方选择，生存平衡尚待游玩。
