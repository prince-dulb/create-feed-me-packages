## 安装

1. 使用 Minecraft 1.21.1／NeoForge 和 Java 21；准备 Create 与 Curios，版本见依赖说明。
2. 将上面的唯一主 JAR 放入**单独测试实例**的 mods 目录。一个实例只加载一个 FMP JAR；旧包可自行移到另一个备份目录，不要并装。
3. 新建测试世界。旧 `test.N` 没有存档兼容合同，不在唯一的正式游玩存档上试验。

我没有自动安装到你的 PCL 实例，也没有修改或删除任何用户存档。

## 本版包含

普通供应链坠与私人定坠、精确组件缓存、1—5级序列升级与原子私人化、真实补货、满背包收件与残包、Create 风格面板、原版／JEI合成取料与标准弹药。纸飞机和运输蜂均完成原生补货联调。

**本版没有退货、实际插件、TaCZ 或护甲入口。** 五级插件槽权益已保留，但不显示空插件舱。

高级成本体现为材料获取难度、复合零件和加工链。具体生存投入还需要你的体验反馈，不宣称已测出严格的指数小时数。
