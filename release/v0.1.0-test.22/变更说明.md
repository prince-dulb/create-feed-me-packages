# Create: Feed Me Packages! 0.1.0-test.22 — 变更说明

## 相对于 test.21 的变更

### 修复滑条被物品图标遮挡（z-order 层级问题）

- `renderSlider()` 用 `translate(0, 0, 120)` 将滑条提升到 z=120，但 Minecraft 的 `renderItem()` 内部用 z≈200 渲染物品图标。物品图标 z > 滑条 z，导致滑条背景被物品遮挡。
- **修复**：滑条 z 偏移从 120 提高到 250，确保滑条渲染在物品图标（z≈200）之上。

- JUnit：16/16 通过
- GameTest：84/84 通过
