# Create: Feed Me Packages! v0.1.0 — 验证记录

## 概述

`v0.1.0` 是「机械动力：喂我发包！」首个本地可玩版本，基于 test.24 代码（私人定坠物主锁定、残包按物品格分格、精确组件身份、真实补货与收件口、合成/JEI/标准投射物）。本目录为**本地交付**，不等于公开发布。

- Java: OpenJDK 21.0.7（`java-runtime-delta`）
- Gradle: 8.12, NeoForge 21.1.219
- 代理: `127.0.0.1:7890`（进程级 `GRADLE_OPTS`）
