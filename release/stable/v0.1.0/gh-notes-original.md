# Create: Feed Me Packages! v0.1.0

Create 的附加内容，为这游戏补上一条"物流缓存"玩法——供应链坠会把物资集中存放，到期自动向 Create 网络下单补货。

## 功能能力

- **供应链坠（普通）**：稳定访问一份随坠子转交的物流缓存；玩家可在此设过滤、库存上限与补货下限。
- **供应链坠·私人定坠**：按佩戴玩家访问个人缓存；私人化绑定锻造者，物主可直接升级共享个人缓存，他人佩戴时退化为全新普通坠。
- **1—5 级缓存**：每级依次开放 9／16／24／30／36 个物流格与 128／256／512／1,024／2,048 的单格容量；永久升级经 Create 序列组装与锻造台。
- **真实补货**：低于补货下限向 Create 网络下单，纸飞机／运输蜂按原生方式送达；本模组在玩家侧接收完整专用包。
- **补给与取出**：从背包存入实物即转真实库存；取出回归原生背包／快捷栏语义；配方书、JEI 配方查看与填充、原版投射物链均可自动供料。
- **依赖**：Minecraft 1.21.1、NeoForge 21.1.219、Create 6.0.10、Curios 9.5.1（四项 required）。JEI、运输模组为可选联动，缺失不影响核心运行。

## 平台

- Minecraft 1.21.1 / NeoForge 21.1.219（Curios 项链槽作为首个版本唯一佩戴入口）。
