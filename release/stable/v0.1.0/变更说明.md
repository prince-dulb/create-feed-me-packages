# Create: Feed Me Packages! v0.1.0 — 变更说明

## 本版本相对前序测试版（test.24→test.23→…）的累积变更

`v0.1.0` 是首个本地可玩版本，由连续测试迭代收敛而来。最后两轮（test.23、test.24）的核心变化：

### test.24：私人定坠物主锁定
- 私人化写入锻造者为物主（`OWNER` UUID + 物主名）；整份内容转入锻造者的个人缓存（放不下整体拒绝）。
- 只有物主佩戴访问其个人缓存；同一物主所有私人定坠共享同一缓存与等级；物主在锻造台直接升一级（可连续到 5 级）。
- 非物主佩戴即退化为全新普通供应链坠（带新本件缓存），无法触碰物主私人缓存。
- 移除「待签收容量授权/佩戴签收」（`CAPACITY_GRANT`、`grants` 表、`prepareGrant/prepareClaim/pending/claimPending`）。`SCHEMA 6→7`。

### test.23：残包按物品格分格
- 残包从「每缓存一个」改为「每个物品格一个」（按精确变体），不同物品格互不阻塞。`SCHEMA 5→6`。
- 成长链与面板提示精简。

### 更早（test.17—test.22 收敛）
- 计数按组容量模型（`SCHEMA 5`），滑条覆盖层、逐格残包绿点、层级修复、统一组容量。

## 本版本核心玩法

- 两类终端：供应链坠（随物品转交的本件缓存）、供应链坠·私人定坠（物主锁定的个人缓存）。
- 1—5 级：9/128、16/256、24/512、30/1024、36/2048（格/单格容量），插件槽权益 1—5（首版不显示空舱）。
- 永久升级用 Create 序列组装链节 + 锻造台。
- 精确组件物品身份，补货只统计缓存现货，真实收件口与后台残包。
- 固定背包优先、原版合成/JEI/标准投射物取料。
- 依赖声明仅 Minecraft/NeoForge/Create/Curios 四项 required。

## 已开放物品

供应链坠、供应链坠·私人定坠、装配图、私人化链节、四种扩容链节（1—4号）及框架/未完成中间件，均在独立创造模式标签页可用（不依赖 `/give`）。

## 已知边界（真实存在，非隐藏）

- JEI ghost 拖拽设过滤暂停（配方查看/填充保留）。
- TaCZ、无 Curios 入口、自定义背包访问/更多合成同为后续版本；退货在 `v0.2.0`，插件在 `v0.3.0`。
- 运输模组（纸飞机/运输蜂）只做首版真实补货联调，未写入依赖声明；本次未重跑其完整组合联调。
