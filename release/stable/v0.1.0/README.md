使用 Minecraft 1.21.1、Java 21、NeoForge、Create 与 Curios。客户端和服务端使用同一正式版本，只放一份 FMP JAR；更新前正常退出并备份存档，不在唯一世界上做异常测试。可选 JEI／运输模组按各自依赖和已验证组合安装，不要同时放入其他 test.N。
