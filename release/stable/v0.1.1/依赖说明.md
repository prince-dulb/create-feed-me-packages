# Create: Feed Me Packages! v0.1.1 — 依赖说明

## 模组依赖声明（`neoforge.mods.toml`，生成后确认）

只声明以下四项 required 依赖，未新增可选依赖：

| 依赖 | 版本 | 关系 |
| --- | --- | --- |
| Minecraft | 1.21.1 | required |
| NeoForge | 21.1.219 | required |
| Create | 6.0.10（Maven `6.0.10-280`） | required |
| Curios | `9.5.1+1.21.1` | required |

JEI、Create More: Package Couriers、Create: Mobile Packages 等**不写入依赖声明**；实现兼容时使用隔离模块与运行时存在性探测，缺失或版本变化不阻止核心加载。

## 实际测试组合

- 核心（无 JEI/运输）：NeoForge 21.1.219，GameTest 世界 `-model8`。
- 跨 JVM 回读：读前一 JVM 写入的真实玩家文件、Curios 与 schema 7 缓存账本。
- 人工：用户生存档实测（2026-09-07，基于 v0.1.0/test.24）。

## 数据格式

- `CacheLedger.SCHEMA = 7`（残包按物品格；私人定坠物主锁定；移除授权 grants 字段）。
- 私人定坠新增 `OWNER`（UUID）、`OWNER_NAME`（物主名）数据组件。
- 提供 schema 2/4/5/6→7 迁移；旧 schema 6 世界里的授权表视为废弃忽略。
- 未发布内部测试世界、旧 `test.N` 数据不构成存档兼容合同；旧世界目录保留未删。

## 兼容与边界

- 本期未重跑纸飞机/运输蜂/JEI 的完整组合联调；缺失它们时核心仍加载（核心 GameTest 已证）。
- 本项目为本地交付，并非公开发布；安装到的整合包需按其自身规则验证。
