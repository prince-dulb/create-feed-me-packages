# Create: Feed Me Packages! v0.2.0

## 相对 v0.1.1 的变化

### 自动退货

- 每个缓存可设一个默认退货地址。某格现货超过你设的最高值时，超出部分自动打包，由纸飞机或运输蜂送回。
- 只有载体**真实受理**后才扣缓存与载体；无载体或发运失败时不打包、不扣物。
- 面板该格显示退货箭头：真实发运成功且仍超额为红色，其余为灰色，退到最高值后消失。

### 取物预留

- 从缓存格取出时先在光标上预览，缓存数量不变、不触发补货；真正放进背包／合成格／地面才扣减。
- 放回净零；关闭界面或卸下饰品会取消未落位预览并留在缓存。

### 容量按“组”

- 1—5 级单格容量统一为 2／4／8／16／32 组，按物品自身堆叠上限换算。
- 滑条以“组”为刻度，下端点设最低值（补货）、上端点设最高值（退货，最右为不退货）。

### 满背包收件与逐格残包

- 背包与快捷栏全满时，专用包裹仍能进入缓存；装不下的部分按物品格保留为残包（左下角绿点），有空间时自动续收。

### 修复

- 创造模式存取不再复制物品；手持物品图标不再错位；面板／滑条／提示层级修正。
- 滑条端点不再超出轨道 1px，拖动跟手；按住端点不动不再改变数值。

## 注意

- 缓存 schema 为 **8**、面板网络协议为 **4**；同一存档请让客户端与服务端使用同一份 0.2.0，不要混装旧客户端与新服务端。
- 依赖：Minecraft 1.21.1 / NeoForge，需要 Create 与 Curios；JEI 与纸飞机／运输蜂模组均为可选。
