# v0.1.0-test.6 依赖说明

本目录是本地测试交付，不是公开发布版。

## 加载器依赖

- Minecraft `1.21.1`
- NeoForge `21.1.219`
- Create `6.0.10`
- Curios API `9.5.1+1.21.1`

生成后的 `neoforge.mods.toml` 只有上述四项 required 依赖。JEI、Create More: Package Couriers、Create: Mobile Packages 均未声明为 required 或 optional。

本构建新增了本地收包侧：地址为 `FMP@玩家名` 的 Create 完整包裹进入背包后会自动拆入个人缓存并结算待收。纸飞机／运输蜂的完整运输联调（C2／C3）仍未完成，当前到达的实体包由 T06 请求侧真实 Create 打包机产生。未安装这些模组不阻止核心模组加载。
