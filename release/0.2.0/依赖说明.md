# v0.2.0 依赖与边界

Minecraft 1.21.1，Java 21，NeoForge。模组声明只包含 Minecraft、NeoForge、Create 和 Curios；不声明 JEI／运输模组依赖。

| 项目 | 本轮实际版本 |
| --- | --- |
| NeoForge | 21.1.219 核心；21.1.249 完整组合、客户端与成品运行 |
| Create | 6.0.10-280 |
| Curios | 9.5.1+1.21.1 |
| JEI（可选） | 19.51.0.418，与 NeoForge 21.1.249 组合 |
| Package Couriers（可选） | 2.3.0，纸飞机 |
| Create: Mobile Packages（可选） | 1.21.1-0.7.7，运输蜂 |

Create 测试环境还包含其所需 Registrate、Ponder 1.0.82、Flywheel 1.0.6 及 Vanillin 1.1.3。实际文件以构建输入为准，不需要额外下载本模组专用库。

JEI 19.51.0.418 自身要求 NeoForge 至少 21.1.238，不能与 21.1.219 组合；这不是 FMP 给 JEI 加的上限。

面板协议标识在本版为 **4**（test.56 为 3，因快照新增每格退货状态字段）。**同一存档请让客户端与服务端使用同一份 test.58**；不要混装旧客户端与新服务端。未做混装实验，不声称已观察到断连。

纸飞机和蜂依然需要各自的地址、网络／成员与可达条件；发运前拒绝不消耗货物或载具，发运后沿用原生运输、失败与回收逻辑。未装运输模组时核心缓存仍可用。

TaCZ、插件、第三方背包入口不在 0.2.0 收尾范围内。用户实例未被本轮测试修改；两份 test.57 候选与 test.56 交付均保留。
