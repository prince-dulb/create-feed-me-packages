# test.15 复测清单

使用独立测试世界，只安装一个FMP版本；需要联机时双方同步test.15。基础制造与绑定见[完整说明](../../reference/v0.1.0/docs/PLAYER_GUIDE.md)。以下重点由你在实际整合包里复查，自动化结果不能替代操作手感。

## 优先检查

1. **右键单件。** 生存模式从背包拿起7个物品，右键空缓存格一次：缓存1、光标6。再右键一次：2／5；左键放完：7／0。创造模式再试一遍，并把取出的物品放进原版物品栏、关闭重开，确认不多出一份。
2. **面板操作。** 在常用GUI缩放下检查格距、小点、箭头、数量和滚动末行；滑条只出现在选中行下方。点击顶部剪贴板应复制地址。确认没有等级、终端管理、残包或优先级按钮；告诉我还有哪些提示或命中区妨碍操作。
3. **JEI停用范围。** 拖JEI物品到空缓存格不应设置过滤或增加物资。先从背包存入实物设过滤，再用JEI查看配方、填充原版合成格；准备不扣缓存，真实合成才扣。锻造／序列配方仍应能看到输入和成品。

## 顺手回归

4. **绑定／清绑。** 手持坠子潜行右键网络设备后出现绑定光效；手持对空气右键后清除光效和网络，原库存不变。再绑定并佩戴，面板恢复。指向普通方块右键不应误清绑。
5. **后台余货。** 制造一份超过当前可用容量的迟到包：例如补货已出发时先手动填满缓存。包到后逐步取出库存，余货应自动补入；没有手动残包按钮。卸下后停止，再佩戴恢复。正常匹配但容量满的余货不会自动丢进普通背包。
6. **第二件。** 如果你的整合包允许多个项链槽，已有普通或私人坠子时，另一件仍不能再佩戴。卸下原件后可以换上新件。只有一个槽时无需为这项另装模组。

过滤失效时的后台整包交还、满背包等待、手动开包后不留假状态、异常多件防御、跨JVM保存及后台交还不影响正在使用的弓已有专门GameTest；遇到实际异常仍请报告。

反馈尽量带上：生存／创造、GUI缩放、装的是哪件坠子、操作前后缓存／光标／背包数量、最短步骤；有录屏或崩溃日志时附上。没有异常时直接报上述编号通过即可。完整美术与生存升级成本仍另作体验讨论。
