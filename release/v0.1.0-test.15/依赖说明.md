# 依赖与安装边界

## 必需

| 项目 | 实测版本 | 本包元数据声明 |
| --- | --- | --- |
| Minecraft | 1.21.1 | 仅1.21.1 |
| NeoForge | 21.1.219、21.1.249 | 21.1.219及以上 |
| Create | 6.0.10-280 | 6.0.10及以上、低于6.1.0 |
| Curios | 9.5.1+1.21.1 | 9.5.1及以上、低于10.0.0 |

使用Java21。Create自身所需的组件按其发行包和加载器提示提供；FMP没有把第三方代码或资源重新打包进来。声明范围不是所有未来版本均已实测的承诺。

## 可选

| 模组 | 本轮实际验证 |
| --- | --- |
| Package Couriers（纸飞机） | 2.3.0；单装和与运输蜂共存的服务端物流链 |
| Create: Mobile Packages（运输蜂） | 1.21.1-0.7.7；单装和与纸飞机共存的服务端物流链 |
| JEI | 19.51.0.417、19.51.0.418；NF21.1.249上的实际客户端配方查看／填充／制造展示 |

这三者**都不写入FMP的required或optional依赖声明**。JEI拖拽设过滤暂时停用，不代表JEI其他功能被禁用，也没有新增JEI版本上限。JEI418组合使用NF21.1.249，不绕过JEI自身的平台要求。

只需本地存取时，不必安装运输模组；自动物流仍需能实际将Create包裹送给玩家的设施。纸飞机与运输蜂都按原生规则运行，FMP不替它们建站或加入网络。

## 安装与已知情况

在自己的测试实例中只保留一个FMP JAR，客户端与服务端同步使用test.15。面板协议本轮更新，不能混用旧客户端；持久化schema没有变化，但未发布测试模型没有存档兼容承诺，也没有迁移模块。代理没有替你移除旧包或操作存档。

双运输共存时，当前Package Couriers的`deploying/jar_plane`、`portable_stock_ticker`和`portable_stock_ticker_clear`三条上游配方仍报解析错误。日志如实保留；本轮FMP真实收货与成品启动通过不意味着这些上游配方已修复。未验证用户完整PCL整合包中的所有其他模组组合。
