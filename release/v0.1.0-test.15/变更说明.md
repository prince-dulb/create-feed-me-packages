# test.15 变更说明

## 操作与面板

- 持物右键缓存格只存1件，左键按剩余容量尽量存入；按下／松开之间收到服务端应答也不会重复提交。生存和创造分别处理合法光标，保留test.14的原生创造交接修复。
- 两类坠子合计最多佩戴一件。额外项链槽不放开第二件；异常强制多件时停止缓存业务，卸下多余件恢复，不提供管理页面。
- 潜行右键提供Create物流联网行为的设备绑定，沿用本体交互权限；手持对空气右键清绑。指向方块时不因使用失败误清网络，清绑不删缓存、请求或制造权益。
- 格子改为18像素尺寸与间距；小点置于格内右上、箭头在左上，选中行下方展开紧凑滑条。保持数量、滚动、数值精调和按格请求重置。
- 移除常驻等级、个人标记、页码和管理／残包按钮；复制地址缩为顶部剪贴板图标。保留必要的短提示，本轮不宣称完成美术体系重做。

## 残包与JEI

- 残包完全在后台续收，先处理已有实物再检查补货；普通容量不足继续保留余货。
- 过滤失效或余货没有对应过滤时，只有原版背包能容纳完整真实包裹才自动交还；否则继续保留。不掉地、不销毁、不增设收纳槽，也不反复接管无法入库的已到达包。
- 后台交还只更新实际变化的背包格，避免替换正在使用的弓的真实堆栈引用。新增回归先复现该问题，再验证修复后的引用与实际耐久消耗。
- 暂停JEI ghost拖拽设过滤，服务端同时拒绝旧设模板意图；保留实物设过滤、JEI配方查看／填充、制造展示与遮挡避让。不把暂停说成原ghost问题已经修好；恢复入口需另行设计。

## 保持不变

普通／个人缓存归属、精确组件身份、真实包裹补货、合成可撤销预留、固定背包优先、标准投射物取料和五级序列制造均保留。持久化schema不变；面板通信版本更新，旧客户端不得混连。

没有退货、插件、TaCZ消费、独立界面或根工程移植。0.2先做退货、0.3再做插件的路线仍有效，本次交付不自动启动下一版本。
