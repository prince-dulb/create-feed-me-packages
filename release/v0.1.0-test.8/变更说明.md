# v0.1.0-test.8 变更说明

本构建只修复一项客户端渲染缺陷，回应 test.7 复测中"被拿起的物品图标错位复制"的反馈。游戏规则、服务端逻辑、转移守恒行为与 `test.7` 完全一致。

## 修复：手持物品图标在物流面板上错位复制

`test.5` 引入的"光标副本"用于解决"面板绘制在原版界面之后、盖住手持物品图标"的层级问题，但绘制时使用了 `鼠标 +10,+10` 的偏移锚点——原版的手持图标绘制在 `鼠标 -8,-8`。结果手持物品走到面板上方时，屏幕上出现一个偏离光标的第二份图标，看起来像物品被错误复制且位置错乱。

现在副本严格按原版锚点绘制（`鼠标 -8,-8`，物品层之上），与被面板盖住的原版图标完全重合：手持物品经过物流面板时只显示一个位置正确的图标。

## 复测要点

- 手持任意物品（从缓存格或背包取出后）在物流面板上移动：应始终只有一个图标，且跟随光标、无偏移、无重影。
- 从面板移动回背包区：图标连续，位置不变。
- `test.7` 的其余复测项（五项界面 + 四项收包 + 手动放取 + UI 响应）在本构建仍然有效。
