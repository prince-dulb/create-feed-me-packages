# v0.1.0-test.8 依赖说明

本目录是本地测试交付，不是公开发布版。

## 加载器依赖

- Minecraft `1.21.1`
- NeoForge `21.1.219`
- Create `6.0.10`
- Curios API `9.5.1+1.21.1`

与 `test.7` 完全一致：生成后的 `neoforge.mods.toml` 只有上述四项 required 依赖，JEI、Create More: Package Couriers、Create: Mobile Packages 均未声明为 required 或 optional，缺失这些模组不阻止核心加载。

本构建只修复一个客户端渲染问题（手持物品图标在面板上错位复制），服务端逻辑与 `test.7` 完全相同。
