# 变更说明 — v0.1.0-test.18

基于 reference/v0.1.0 (test.16) 直接接手，在其已验证代码上做最小手术式修改。

## 三项新需求

### A. 组数计数
- 新增 `MaterialVariant` 接口（`domain/`），唯一方法 `int stackSize()`
- `ItemVariantKey` 实现 `MaterialVariant`，构造时从 `ItemStack.getMaxStackSize()` 捕获 `stackSize`
- 域模型泛型绑定 `K extends MaterialVariant`：`Cell`、`CacheState`、`CacheEdit`、`CacheMerge`、`SupplyOrder`
- `Cell.shortage()` 改为 `minimum * filter.stackSize() - amount`（阈值按组，数量按物品）
- `CacheEdit.insert()` 房间计算改为 `capacity * variant.stackSize() - amount`
- `CacheState` 容量校验改用 `capacity * stackSize`
- `CacheMerge.simulate()` NO_SPACE 校验改用 `capacity * stackSize`
- `CacheLedger` schema 2 → 3
- `PanelPackets.CellView` 增加 `stackSize` 字段，`PanelNetwork` 组装时填入
- 客户端：库存提示显示物品容量（`capacity × stackSize`），箭头条件使用组数比较

### B. 滑条覆盖层
- `PanelLayout.compute()`：滑条不再预留高度（移除 `extra`/`offset`），格子行不因滑条下移
- 滑条定位受 `screenHeight` 钳制（`Math.min(cy + ROW, screenHeight - 4 - SLIDER)`）
- `LogisticsPanel.renderSlider()`：`pushPose/translate(0,0,120)` 提升 z 层级，渲染边框后 `popPose`
- `release()`：鼠标释放在滑条区域时不触发存入（守卫条件）

### C. 逐格残包绿点
- `PanelPackets.CellView` 增加 `boolean residual` 字段
- `PanelNetwork.snapshot()`：遍历残包内容，匹配每格 filter 设置 residual 标志
- `LogisticsPanel.renderCell()`：当 `cell.residual()` 时渲染 3×3 绿色圆点 `(x+1, y+13, 0xFF82C665)`
- 移除面板级黄色脉冲残包横条
