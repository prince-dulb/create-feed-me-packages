## 请人工复测

1. 给任意过滤格放入物品，确认左下状态箭头与悬停时右上设置点都显示在物品图标上面。
2. 悬停底部“取料：背包／取料：缓存”，确认说明容易理解；点击可切换。该开关当前不应改变补货行为。
3. 悬停任一缓存升级件，按提示装备供应链坠、手持正确的下一阶段升级件右击，确认阶段、格数与容量更新。
4. 创造模式从物品目录依次拿不同物品，放入多个空物流格；确认每格都能建立过滤、不再提示“尚未接入”，数量均为 0，光标图标不挡住目标格中心。
5. 对 0 库存过滤格按住 Shift 右击，确认过滤清除；再打开另一个 0 库存格的小滑条并按 Delete，确认旧入口也有效。
6. 在创造背包标签中，从玩家真实背包 Shift 左击一种尚无过滤的物品，确认第一个空物流格建立过滤并收到真实物资；生存界面不应因此自动占用空格。

不必重复测试 T06 自动拆包：本构建仍不会在包裹抵达后自动拆入缓存，手动拆包也不会结算待收箭头。
