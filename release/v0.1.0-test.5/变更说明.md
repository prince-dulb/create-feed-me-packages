# v0.1.0-test.5 变更说明

本构建针对 `v0.1.0-test.4` 人工验收发现的界面与说明问题修订：

- 状态下箭头与设置点改在物品图标上层绘制，不再被图标遮住。
- 底部来源开关缩写为“取料：背包／取料：缓存”；悬停说明它决定未来自动合成和弹药取料顺序，当前只保存偏好，不影响补货。
- 四种缓存升级件增加使用 tooltip：装备有效供应链坠后，手持正确的下一阶段升级件右击，并显示目标格数和单格容量。
- 接通创造物品目录的 ghost 过滤：可在多个空格设置过滤，缓存库存保持 0，不再提示“该操作尚未接入”。
- 创造界面中的光标物品副本移出目标格中心，便于观察落点。
- 0 库存过滤格可用 `Shift + 右击` 清除；打开滑条后按 Delete 的入口继续保留。
- 创造模式 Shift 左击玩家真实背包物品时，如果没有匹配过滤，会使用第一个已解锁空格建立过滤并存入真实物资；生存界面仍只存入已有匹配过滤。

包裹到达后自动拆入缓存、手动拆包识别与待收箭头结算仍属于 T06 收包侧，`test.5` 只记录、不实现。
