## 结论

旧 plan-v1.0 的玩家单缓存、材料等级名、简易升级配方、旧 T00—T15 未来路线和预发布兼容假设已经失效。当前产品以[plan-v2.0 项目计划书](../项目计划书.md)为唯一入口，当前分期以[plan-v2.0 版本路线图](版本路线图.md)为准。

新模型的基础是：

- 普通供应链坠访问随物品转交的本件缓存；
- 供应链坠·私人定坠访问随玩家的个人缓存；
- 正式等级为 1—5 级，固定 9／128／1 到 36／2,048／5；
- 永久升级走 Create 序列组装；
- 插件是后续独立构筑系统，玩家只看到通用槽；
- 包裹必须携带目标缓存路由，满背包使用服务收件口与一个真实残包槽；
- 项目尚未发布，不为旧 `test.N` schema 或物品 ID 建兼容／迁移模块。

受影响源码、schema 和注册 ID 继续冻结。R0 的产品门、技术 Spike、详细规格和用户实施授权未完成前，不得制作 `test.13`。

## 历史证据边界

`test.12` 及此前构建、单测、GameTest、客户端和专服结果继续作为“旧代码曾经做到什么”的证据。它们不证明本件缓存、私人定坠、服务收件口、序列升级、插件权益或新包路由已经实现，也不形成旧数据兼容义务。

精确组件 `ItemVariantKey` 的产品语义继续有效；旧 schema 1→2 迁移仅保留为历史实现事实。当前模型只验证干净 schema 的首次创建、保存重载和坏数据拒绝。
